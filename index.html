em·ji·ve

My brother and I co-founded a jewelry brand. The challenge was for the website to serve both as a gallery and a shop. I prototyped it in Affinity to define the visual identity and main behaviors. Then I built it from scratch and iterated with a few test users.

Prototype

Result

Phone Desktop

Home page

  • The ring wheel on the home page remembers the ring that was in focus, so a visitor who comes back finds their place instead of starting over.
  • Some buttons have hit areas larger than they look, so they stay small on screen and easy to hit.
  • When a 3D model sits untouched for three seconds, a hand nudges it to show it can be turned. Once a visitor has turned any model, no model nudges again for the rest of the visit.
  • On phones, shape, material and size each get a dial, so a visitor can configure the whole ring on one screen.
  • The size slider gets more precise as the visitor slows down: quick moves cover the whole range, slow ones settle on an exact size.
  • Visitors unsure of their size get three ways out: order a sizing strip, with free shipping on the next order, measure a ring they already own on their phone's screen, or read the size chart.
  • Removing a piece from the order leaves an Undo in its place, so a slip of the finger costs nothing.

User feedback

  • Testers arriving on the home page looked at the hand and did nothing, so I added a "Scroll to scan" tattoo on the hand to tell them what to do.
  • Testers going through the site asked to see the rings side by side, so I built the grid view.
  • A tester confused the ring sizes, shown in millimeters, with the dimension lines on the 3D model, also in millimeters. Sizes now show as a number with no unit.
  • A tester didn't recognize a button in one place on the site, so I moved it into a section of its own.

Folder manager

During my internship as a project manager, I noticed that creating new projects' folder trees and moving them around was taking a lot of time. And doing it by hand left a fair amount of inconsistencies and naming errors in the folders.

So I built a Google Drive add-on to reduce the time spent creating and moving folders and to harmonize the naming and folder structures.

Result

Time spent on project folder admin cut by 92%, from 4.5 to 0.3 minutes, and no more inconsistencies in folder naming and structure.

Add-on home

  • The team already works in Google Drive, so the tool lives there as an add-on instead of a separate web app they would have to open.
  • The home panel has one action for each turn in a project's life: New project creates its folder tree, either in negotiation or directly as a running project, Mark as won turns a project in negotiation into a running one, and Close a project marks it as finished or lost.
  • Folders created before the add-on don't all follow the naming convention. A Maintenance section shows the ones that don't and lets the user fix them.
  • The add-on reads the folder structure and the templates from a single source of truth, so changing the agency's conventions means editing one place.
  • A project in negotiation has no project ID: one is only generated once it is running. So Mark as won asks for it, from the quoting software.
  • Closing a project asks whether it is finished or lost. The two are kept apart: each goes to its own parent folder.

User feedback

  • One of the CEOs asked for a quick way to reach a folder once the add-on had created or moved it, so I added a "Go to folder" button at the end of both actions.

ACE

Blender add-on that turns live audio into animation data through a node-based interface. Blender alone only bakes audio files into keyframes.

Decisions

  • I built a node-based system on top of the add-on's UI panels, so the engine slots into Geometry Nodes workflows, which already run on nodes.
  • Each feature appears when the typical workflow reaches it, so new users learn the tool by using it instead of facing every option at once.
  • An Audio Preview node plays the sound as the node chain filters it, so the user can hear which part of the music an animation is reacting to.
  • The audio analysis runs in separate processes, away from Blender's interface, so the viewport doesn't stall while the music plays.
  • The add-on's preferences list the libraries it needs and install the missing ones with one button.

Result

An audio analysis engine with a set of operators inspired by TouchDesigner, the industry leader, in a node-based interface that integrates cleanly with Blender's Geometry Nodes editor for real-time 3D geometry manipulation.
